# Diagrams

The SVG and draw.io files in this directory are historical architecture drawings.
They are retained as design artifacts, not as a current protocol or ownership
specification. In particular, deployment layout, VM state ownership and available
backends have evolved.

The current [architecture guide](../ARCHITECTURE.md) contains Mermaid diagrams for
component relationships and reconciliation flow. Mechanism guides add diagrams at
the point where they explain the implementation. Edit those sources when behavior
changes; do not infer guarantees from a connection arrow alone.
