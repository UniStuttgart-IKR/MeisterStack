# AI contribution guidance

MeisterStack used Claude Code during prototyping and Codex for source review and
documentation. AI assistance does not replace contributor responsibility.

- Understand every change you submit and be able to explain its behavior.
- Check generated claims against the implementation and tests.
- Keep executable evidence separate from assumptions and proposed designs.
- Mark AI-assisted documentation with a note in its documentation index or the
  document itself. Record the scope and limits of substantial reviews.
- Do not present generated prose or test output as independent human review.
- Write issues, reviews and other human conversations yourself.

Early agent development combined hand-written code with reviewed generated
snippets. Later controller development used larger agent-assisted implementation
and test tasks. Historical lab work belongs to its experiment records; it does not
establish that every current path has been exercised.

This is active thesis software. Review coverage, known defects and validation limits
should remain visible while the implementation evolves. See
[acknowledgements](ACKNOWLEDGEMENT.md).
