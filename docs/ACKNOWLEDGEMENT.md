# Acknowledgement

This project is developed as part of a master thesis at the University of Stuttgart at 
the IKR (Institute of Communication Networks and Computer Engineering).

- Author: Silas Müller B.Eng.
- Supervisor: Nicolas Horneck M.Sc.

The following LLMs/AI-Tools were used during documentation and development:
 - Claude and Claude Code with the models (Sonnet, Opus and Fable)
 - DeepL Write to improve text

*For more information on the usage of LLMs and AI please refer to the [AI-Guidelines](AI_GUIDELINES.md)*

During the research of this thesis [Project Leandro](https://github.com/UniStuttgart-IKR/Leandro) was created
as an offspring of this project. Project Leandro enables the paravirtualization of (NVIDIA) GPUs on a driver level.
To do so a dedicated vhost-user device was implemented with its guest kernel modules.
Project Leandro's goal goal is to get as much code in related upstream repositories as possible.
